# HW08：聚餐分帳計算器 (Dinner Split)

本專案為逢甲大學行銷學系課程作業（HW08），由學生 **松尾和磨（學號：d1429682）** 透過 AI 協作撰寫 Python 聚餐分帳程式。

## 一、功能說明
- **金額與服務費計算**：輸入聚餐原始總金額與服務費百分比（如 10%），自動計算服務費與含稅總金額。
- **平均分攤計算**：依據輸入的聚餐人數，計算每人平均應付金額。
- **防呆機制（例外處理）**：使用 `try-except` 攔截非數字輸入，並檢查人數大於 0 與金額非負數之條件。

## 二、Vibe Coding Prompt 紀錄
> **Prompt 內容**：
> 「請用 Python 寫一個聚餐分帳計算器（dinner_split），讓使用者依序輸入總金額、服務費百分比與分攤人數，計算出含服務費後的總金額以及每人應付金額，並加入輸入錯誤與人數為零的防呆處理，整理成 Jupyter Notebook（.ipynb）格式。」
